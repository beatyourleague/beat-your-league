# Retired drafts — the Sleeper league product

These were written by `run/content.py` from a 2018 Sleeper sample league: its
history, its transaction log, its managers' behaviour. The product reads no
league any more, so none of them could be produced today and none of them
should be posted.

They are kept rather than deleted for the same reason `reports/backtest.md`
is kept — it is what the earlier product did — and moved out of `content/`
because the live drafts land there and the Monday artifact ships that whole
directory. A Hype Wednesday draft sitting beside this week's Receipts post is
an invitation to publish a format that no longer exists.

The live path is `run/posts.py` (`make content`).
